# photographic-print-edit · 摄影精修 Skill

让摄影后期围绕具体的观看意图展开：先实际看原图，再决定画框、局部光色和干扰处理，最后重新打开每张成片验收。适用于旅行风光、环境人像、建筑和动物摄影。

这个 Skill 总结了真实修图迭代中的经验：多个文件不一定等于多个构思；去物要检查残枝、倒影与被遮挡背景；局部 AI 不能靠提示词保证范围；生成好看的环境也不能悄悄改变人物身份；文件数量正确仍需按原片编号核对对应。

## 使用

将本仓库完整目录保存为 `photographic-print-edit`，放入自己的 Codex skills 目录，保留 `SKILL.md` 与 `references/` 的相对结构。也可以直接让支持文件读取的代理阅读 [SKILL.md](SKILL.md)。

示例请求：

```text
使用 $photographic-print-edit，去掉这张照片左侧的树。
保留雪峰、右侧红叶、构图与调色，另存新版。
```

```text
使用 $photographic-print-edit，为这组照片各做两个不同构思的彩色精修版。
保留人物和动物的身份、姿态与数量关系，AI 仅用于天空、去物和局部修补。
输出按原片编号组织的成片、对照图与 JSON 索引。
```

Skill 是工作方法，需要运行环境具备实际读图、图像编辑和文件保存能力。RAW 显影、受限蒙版、分层工程及生成式编辑是否可用，取决于当前工具；本仓库不内置图像引擎，不要求固定服务或模型。
