# 局部 AI 与保真验证

用于局部去物、换天、替换小块文字，以及用户明确要求保留其他区域的委托。按实际工具能力选择实现，不假设生成器提供可靠蒙版或原尺寸输出。

## 先确定保护的含义

| 委托 | 基准与验收 |
| --- | --- |
| 保留本人、车或地标，允许调色 | 保留实拍身份与结构；RGB 可以随获准光色调整改变。看脸、手、器材、轮毂、轮廓，不能用相似度分数代替。 |
| 只去树／只换署名，其他像素不变 | 以指定输入的解码像素为底板，原尺寸、原坐标、无损导出；编辑支持区域之外的差异像素应为零。 |
| 调色并局部换天 | 先形成经调色的实拍底板，再合成生成天空。可验证天空蒙版外相对该底板保持，但不能称为相对原片完全不变。 |

先确认实际目标边界。画面中多个相邻物体不能因为都在左边就自动一起移除；已有明确上下文或标记时直接沿用。

## 把生成结果当作候选补片

1. 实际读取输入与候选的方向、尺寸、模式和色彩配置。若 EXIF 旋转影响坐标，先在有记录的工作底板中统一方向，并让蒙版使用同一坐标；不要暗中旋转或缩放后声称对应原输入。
2. 候选尺寸或几何变化时，只将所需部分对齐到原底板。对齐检查山脊、建筑直线、地平线等参照；局部结构对不上就退回候选。全图插值不能恢复被生成器改写的相机细节。
3. 编辑蒙版应覆盖授权对象、真实遮挡背景和必要接缝过渡。软边非零处也属于会改变的区域；不能先做全图修改再用扩大蒙版掩盖越界。
4. 以实拍底板保留主体，将生成内容仅放入允许区域。对齐、重采样、羽化及其他合成动作遵守当前环境对编辑工具的要求。不能将没有执行的蒙版流程写成事实。
5. 换天检查杆线、屋顶、发丝与玻璃，兼顾地面受光、反射和空气透视。蒙版单独看，再在亮、暗背景或局部对照中看边缘；主体内部不应被天空权重渗透。
6. 严格局部像素保留时，以 PNG 等无损格式保存，保留适当色彩配置。整幅 JPEG 重压、全局锐化或色彩转换都会使未编辑区域产生差异；另存分享 JPEG 时另行描述其用途。

## 小块文字修正

只改署名或几个字时，优先改可编辑文字层。若只能处理位图，将实际输入与候选对齐，只回贴覆盖旧字和必要背景的小区域，验收旧字没有残影、新字拼写完整。再次核对其他标题、排版和画面未被生成器带动改变。公开署名采用用户在本次任务中明确的名字或笔名；没有指定时省略，而不是从参考页面复制。

## 只读验证脚本

`scripts/verify_preservation.py` 只读取图像并输出数值报告，不修图、不对齐、不调整蒙版。依赖 Python 与 Pillow，仅在环境中需要此检查且依赖可用时运行。缺少依赖时可使用其他可靠像素比较工具，不能将脚本未运行写成已通过。

```bash
python scripts/verify_preservation.py baseline.png final.png --edit-mask edit-mask.png > preservation.json
```

编辑蒙版必须是同尺寸的灰度图：零表示禁止变化，任意非零值表示允许变化。它用于定义“允许变的支持区域”，不是由脚本执行的混合透明度。可用 `--protected-mask protected.png` 标出绝对保护区域（非零为保护），即使与编辑区域相交也必须保持。它只能证明声明区域中的像素约束；蒙版是否忠实表达委托仍需人工核对。

脚本应拒绝尺寸、方向或不支持的表示，而不是静默重采样。读取报告中的模式、ICC 与 EXIF 信息；像素相同但配置不同也可能显示不同。RGB/RGBA 归一化仅为比较表示，不是色彩管理转换；不用于高位深、RAW 或 CMYK 的色彩保真认证。脚本的通过条件与限制以其实际实现和报告为准。

默认仅接受 PNG、BMP 或已识别的无损 TIFF 成片；`--allow-lossy-result` 只用于诊断已有有损副本。退出码 `0` 表示声明区域内无越界变化，`1` 表示发现越界，`2` 表示输入不适用或无效。报告输出到标准输出；Shell 重定向的字符编码由当前 Shell 决定。脚本会同时报告 ICC 和其他颜色元数据差异，它们是显示检查提示，不是像素比较的通过条件。支持的模式、位深和格式以实际脚本限制为准。

数值通过后仍须重新打开真实导出文件，检查修复是否完成、补片与边界是否自然、文字是否正确。保持未改区域与生成区域质量是两个不同的验收结论。
